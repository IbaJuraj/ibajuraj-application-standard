# IbaJuraj Application Standard 1.7.0 RC1 – Adoption Plan

Dohodnuté poradie adopcie:

1. **Kalkulačka 2v1** – nasledujúci build po v1.11 Build 52; live theme fix, About alignment, 1.7.0 conformance a adaptive validation.
2. **Peňaženka Kariet** – nasledujúci build po v1.5.0 Build 52; custom bottom navigation, container-driven layout a whole-app adaptive audit.
3. **Strážca Termínov** – nasledujúci build po v1.56.0 Build 105; 1.7.0 conformance, custom bottom navigation/FAB a iPhone+iPad adaptive audit.
4. **Lex Drive** – nasledujúci build po v1.11.0 Build 195; native TabView variant, About parity a whole-app adaptive/conformance audit.

Po každej adopcii sa zaznamenajú nejasnosti Standardu. Ak sa zistí chyba v samotnom contracte, vznikne RC2. Ak sa contract nemení, po úspešnom cross-app audite sa RC1 môže povýšiť na finálny 1.7.0.
