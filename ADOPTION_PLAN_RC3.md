# Adoption Plan — 1.9.0 RC3

1. **TradeBook** — first RC3 pilot for on-device AI, deterministic local fallback, Release Intelligence and controlled learning.
   - distinguish model support, readiness and successful execution,
   - declare `runtimeKind` / `fallbackKind`,
   - prove deterministic fallback is labeled non-generative,
   - prove learning lifecycle candidate → confirmed → active/usable → revoked/reset,
   - preserve freshness/provenance before Market Intelligence expansion.
2. **Lex Drive** — adopt applicable RC3 AI contracts only where generated assistance is enabled; deterministic/legal authority remains separate.
3. **Strážca Termínov / Peňaženka Kariet / Kalkulačka 2v1** — adopt RC3 AI metadata only if/when AI capabilities are introduced.
4. Cross-app validation: conformance schema/validator, RC3 test matrix and exact-build evidence.
5. Promote 1.9.0 only after pilot evidence shows no regression in stable 1.8.0 contracts.

RC3 remains a candidate; stable public authority remains **1.8.0** until promotion.
