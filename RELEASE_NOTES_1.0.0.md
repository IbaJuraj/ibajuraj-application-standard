# IbaJuraj Application Standard 1.0.0

Prvé verejné vydanie spoločného autoritatívneho štandardu aplikácií IbaJuraj.

## Obsah

- pravidlá MUST / SHOULD / MAY,
- hierarchia spoločného a produktového štandardu,
- spoločná identita aplikácií,
- UX, obsah, prístupnosť a lokalizácia,
- dáta, migrácie, synchronizácia a zdieľanie,
- súkromie a bezpečnosť,
- testovanie a release proces,
- register podpory a verejných odkazov,
- governance, návrhy zmien a výnimky,
- strojovo čitateľné metadata a automatická validácia.

## Prvé evidované adopcie

- Strážca Termínov v1.53 Build 43,
- Lex Drive v1.5 Build 120A.

Aplikácie si majú pripnúť tag `standard-v1.0.0` a evidovať prijatie v `APP_STANDARD_ADOPTION.md`.
